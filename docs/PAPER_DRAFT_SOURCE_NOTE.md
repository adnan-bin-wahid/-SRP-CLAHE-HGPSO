# Supplied Manuscript Basis

This codebase was built against the user-supplied pre-experiment manuscript draft titled:

**Spectral-Ratio-Preserving Satellite Image Enhancement Using CLAHE and Budget-Aware Hybrid Grey Wolf–Particle Swarm Optimization**

The implementation covers the proposed four-band common-gain method, analytical-preservation sanity checks, feasibility-first constraints, proxy-resolution hybrid search, same-image baselines, planned ablations, statistical protocol, runtime/memory reporting, and reproducibility outputs.

The manuscript explicitly labels empirical tables as pending measured experiments. This codebase preserves that boundary: report files are populated only from execution outputs.
